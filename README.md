# Chord Progression Builder

A React app for creating and playing chord progressions with Web Audio API.

## Features

- 24 chord qualities with audio synthesis
- 8 artcore presets (Dramatic, Emotional, Epic, etc.)
- Interactive chord palette with drag & drop
- Real-time playback with BPM/time signature control
- Keyboard shortcuts support

## Quick Start

```bash
npm install
npm start
```

Open http://localhost:8080 to use the app.

## Usage

- Click chords to preview
- Click & hold to loop chords
- Drag chords to add to progression
- Press Space to play/stop progression
- Press Enter to add selected chord
- Press ? to show keyboard shortcuts
